# Netem real E2E validation target

Target test host:

`192.236.230.171`

The netem matrix must execute the real APT E2E command on this isolated host. The matrix refuses to run without `APT_E2E_CMD`, so a missing E2E command cannot be mistaken for a PASS.

Example invocation on the isolated host:

```bash
IFACE=eth0 \
TARGET_HOST=192.236.230.171 \
APT_E2E_CMD='YOUR_REAL_APT_E2E_COMMAND' \
./scripts/netem-matrix-v2.sh
```

Required evidence per case:

- process exit status
- SHA256 source/received equality
- stream recovery result
- connection/throughput metrics
- saved log under `artifacts/netem/<case>.log`

The matrix contains seven cases: baseline, 80 ms RTT, 150 ms + 1% loss, 250 ms + jitter/loss, 3% reorder, 3% loss, and 20 Mbit/s + 80 ms RTT.
